# AI Quota Watch

The website half of QuotaPilot. Lives in `site/` of the QuotaPilot repo; `quotapilot share` sends data to it.

Static site that tracks usage limits, plan changes, API prices, intelligence scores and output speed
for ChatGPT, Claude, Grok and Gemini. Live at https://aiquotawatch.pages.dev/ (Cloudflare Pages; GitHub Pages copy as backup). English first, Traditional Chinese via the language toggle
(or `?lang=zh`). Every number carries its source URL and the date it was checked.

## Run locally

```sh
python3 -m http.server 8765
# open http://127.0.0.1:8765/
```

The page loads `data/*.json` with `fetch`, so it must be served over HTTP (not opened as a file).

## Update data

1. Edit `data/plans.json` (plan quotas), `data/models.json` (calculator models), `data/changes.json` (timeline).
2. Every entry needs `source` (https URL), a `checked` date, and `confidence`: `official` only when read on the vendor's own page, otherwise `reported`.
3. Bump `lastReviewed` in each file.
4. Run the checks:

```sh
node scripts/validate-data.mjs   # every number has a source + date, en + zh text
node scripts/check-i18n.mjs      # en and zh strings match
npm test                         # all of the above plus aggregator tests
```

## Community data

Visitors report speed, ratings, quota used and limit/reset events with the form in the Community section.

- With `community.repo` set in `assets/config.js`, the form opens a prefilled GitHub issue labelled `data-report`. Empty = it shows the JSON with a copy button.
- `../.github/workflows/community-data.yml` saves the issue to `site/data/submissions/`, runs `scripts/aggregate.mjs`, and commits `site/data/community.json`. `../.github/workflows/site-pages.yml` publishes the site to GitHub Pages.
- `?demo=1` loads `data/community.sample.json` (generated by `npm run sample`, labelled as example data on the page).
- Tests: `npm test`.

See `docs/codexradar-learnings.md` for which ideas came from studying codexradar.com.

## Monetization (not connected)

`assets/config.js` holds the switches:

- `ads.enabled` / `ads.showPlaceholders`: three ad slots (`top-banner`, `mid-content`, `footer`) render as dashed placeholders. Set `showPlaceholders: false` before deploying if no ad network is connected.
- `affiliates.<provider>`: put an affiliate URL here to replace the official pricing link in "Get a plan". The disclosure line appears automatically and links get `rel="sponsored"`.
