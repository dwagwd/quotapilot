Install with Homebrew

brew tap dwagwd/quotapilot https://github.com/dwagwd/quotapilot
brew install dwagwd/quotapilot/quotapilot

Builds from source on your Mac, about 2 minutes. Needs the Xcode Command Line Tools and macOS 13 or later.

Then launch it: open "$(brew --prefix quotapilot)/QuotaPilot.app". A menu bar icon appears and shows your Codex quota within a minute.

No Command Line Tools yet? Run xcode-select --install first.
